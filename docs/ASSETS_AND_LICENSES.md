## Art, animation, audio

**Every visual and audio asset is generated procedurally at runtime by original code in this
repository.** No external models, textures, HDRIs, fonts, sound files or music are downloaded or
bundled. This is deliberate: the development environment had no network access beyond package
registries, and it avoids every licensing question.

## Relationship to SkiFree

*SkiFree* (1991) was created by Chris Pirih. This project borrows the premise: a skier, obstacles,
and a Yeti that chases you. It uses none of the original's graphics, sprites, sounds, code or
character designs. "SkiFree — The Last Descent" is a working title; before any public or commercial
release, check whether the name can be used.

## Pass 2: licensed-asset investigation (2026-11-07)

The pass-2 brief asked us to investigate licensed assets (PBR textures, trees, characters, HDRIs) for
visual quality, without fabricating any licence. Findings:

- **Network:** only the npm/PyPI/GitHub package registries are reachable from the build machine.
  Asset sites (Poly Haven, ambientCG, Sketchfab, Quixel, etc.) are blocked, so nothing could be
  downloaded from them, and we did not try to route around the block.
- **npm:** `@pmndrs/assets` 1.7.0 (declared CC0) bundles a few Poly Haven HDRIs, Inter fonts,
  test models, and normal maps by "emmelleppi". We could not verify the upstream licence of those
  normal maps from the package alone. Nothing alpine is included (no snow/rock PBR sets, conifers
  or characters), and no other npm package offered alpine assets with a verifiable licence.
- **Decision:** stay fully procedural. Every visual improvement in pass 2 (cave geology, Yeti face
  and fur, trees, terrain shading, atmosphere) is original code in this repository. No third-party
  art is bundled, so no third-party art licence applies. If real scanned assets are wanted later,
  CC0 sources such as Poly Haven and ambientCG are good candidates, but each asset's page must be
  checked and recorded here before use.

## Round 4 Fjord art experiment (branch `fjord-art-r4`, 2026-11-11) — not in the game build

The product owner allowed external assets for the Fjord Coast where they clearly improve the result
and their licence permits redistribution. Findings and decision (details: `docs/ART_PIPELINE.md` §3):

- **Network (re-checked):** from the build machine only package registries, `raw.githubusercontent.com`
  and (for attached repositories only) `api.github.com` are reachable. Poly Haven (`dl.polyhaven.org`,
  `api.polyhaven.com`), ambientCG, jsDelivr, unpkg, OpenGameArt, Kenney and threejs.org are refused by
  the egress proxy. We did not route around the block.
- **No redistributable scanned rock set with clear per-file provenance** was found on npm or in a
  GitHub repository reachable from here. Nothing third-party was downloaded or committed.
- **Decision:** the experiment ships **original textures baked offline by code in this repository**:

| File | Source | Licence |
|---|---|---|
| `src/world/art/textures/gneiss_albedo.webp`, `gneiss_nhr.webp` | Generated by `tools/artbake/bake.mjs` (original code; deterministic) | Same as the project (original work) |

## Round 4 Fjord integration (branch `pass4-fjord`, 2026-11-11) — in the game build

The product owner downloaded Poly Haven scanned texture sets (originals: 4K zips with .blend, kept
outside the repository) and converted them outside the repository to WebP (OpenGL normal maps from
the EXR). The set used in the game was packed into the rock material's two-texture layout at
1K (`tools/artbake/pack_scans.py <dir> <name> src/world/art/textures/<name>`): albedo = scan
diffuse (sRGB) + cavity AO derived from the displacement in A; NHR = normal X/Y (OpenGL), the
displacement as height, roughness. Only these packed files are committed (no 4K, EXR or .blend).

## Round 6 Fjord islands: scanned rock models (branch `pass4-fjord`) — in the game build

Fetched at build time from the Poly Haven API (`api.polyhaven.com/files/{slug}` → the 1K glTF, with
the User-Agent `SkiFree-TheLastDescent-dev/1.0 (build-time asset pipeline)`), kept outside the
repository, and converted with `tools/artbake/scan_to_skm.mjs` (meshoptimizer: positions welded,
simplified to 5,000 triangles, quantised to 16 bits; the scans' own textures are NOT used — the
islands take the triplanar rock material). Only the `.skm` files are committed. The game never calls
Poly Haven. Licence CC0 1.0. Authors from the API `/info/{slug}` records (2026-11-12).
